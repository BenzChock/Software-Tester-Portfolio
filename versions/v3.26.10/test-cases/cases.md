# Selected test cases — v3.26.10

Public adaptations of selected source records. Actions and expected outcomes are summarized for a portfolio. Use synthetic accounts and non-production payment fixtures when reproducing these scenarios.

The original notes do not establish which datasets were synthetic. These public instructions replace identifiable records with generic test fixtures.

<a id="tc-3-26-10-01"></a>

## TC-3-26-10-01 — Activity log filtering

**Action:** Open the activity log and use its search filter.

**Expected:** The log provides a usable search filter.

<a id="tc-3-26-10-02"></a>

## TC-3-26-10-02 — Booking export completeness

**Action:** Export all bookings and then export a filtered selection.

**Expected:** Each export contains records corresponding to the selection.

<a id="tc-3-26-10-03"></a>

## TC-3-26-10-03 — Booking date filters

**Action:** Apply start-date, end-date, and date-range filters.

**Expected:** Only bookings matching the applied filters appear.

<a id="tc-3-26-10-04"></a>

## TC-3-26-10-04 — Voucher entry point

**Action:** Start a booking from the customer portal and inspect payment options.

**Expected:** A voucher action is available.
