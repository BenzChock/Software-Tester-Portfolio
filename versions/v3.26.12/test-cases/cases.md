# Selected test cases — v3.26.12

Public adaptations of selected source records. Actions and expected outcomes are summarized for a portfolio. Use synthetic accounts and non-production payment fixtures when reproducing these scenarios.

The original notes do not establish which datasets were synthetic. These public instructions replace identifiable records with generic test fixtures.

<a id="tc-3-26-12-01"></a>

## TC-3-26-12-01 — Used voucher visibility

**Action:** Use a voucher in a test booking and enable the used-voucher filter.

**Expected:** The used voucher is visible with its used status.

<a id="tc-3-26-12-02"></a>

## TC-3-26-12-02 — Combined receipt filters

**Action:** Combine location, booking, and date filters on the receipt report.

**Expected:** Only receipts matching the combined filters appear.

<a id="tc-3-26-12-03"></a>

## TC-3-26-12-03 — Duplicate unit cards

**Action:** Filter the customer booking page by location and size.

**Expected:** Each available unit card appears once.

<a id="tc-3-26-12-04"></a>

## TC-3-26-12-04 — Booking details navigation

**Action:** Select the booking number from a unit detail page.

**Expected:** The corresponding booking details panel opens.
